# Inventatory-Software

Inventatory is a Windows terminal application for local hardware inventory management and Scan R1 integration.

## Private beta

This repository is private. Invited testers can install release builds using the authenticated GitHub CLI workflow in [the private-beta guide](docs/private-beta.md).
